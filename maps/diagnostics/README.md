# 프로그램 종료 응답 없음 진단

일반 최신 수정본은 `maps/release/GS2vF_ver139.w3x`다. 아래 맵은 원인을 좁히는 진단본이며 해결된 배포본이 아니다.

`GS2vF_ver140_exitdiag.w3x` — 인게임 제목 `가디언 스피리츠 II ver140 [종료진단]`.

사용자는 ver139 싱글플레이 중 바로 프로그램을 종료하면 응답 없음이 생긴다고 보고했다. GSRI는 초기화 시 번개 객체 768개와 64Hz 표시/8Hz 정보 갱신을 만든다. 종료 문제의 후보지만 원인으로 확인되지 않았다. 진단본은 GSRI 초기화만 생략해 사거리 표시/키/마우스/아이템 UI 이벤트 및 관련 객체를 만들지 않는다. 아이템 사거리 기능이 없는 것은 비교 목적이다. 전투 객체 데이터와 나머지 게임 함수는 보존했다. 팀 패널 등 다른 UI는 남아 있다.

ver139와 진단본을 같은 그래픽 설정, 영웅, 플레이 시간으로 비교한다. 직접 프로그램 종료 시 응답 없음 발생 여부와 멈춘 시간을 각각 기록한다. 가능하면 두 번씩 반복한다. 맵에서 메인 메뉴로 먼저 나온 뒤 프로그램을 종료하는 경로도 따로 비교한다.

진단본에서만 정상 종료되면 GSRI/관련 초기화와의 연관성을 좁힐 수 있지만, 이를 원인 확정이나 완전 해결로 해석하지 않는다. 둘 다 멈추면 다른 UI·리소스와 엔진 종료 경로를 추가 조사해야 한다. 싱글플레이에서 발생한다는 사실만으로 Warcraft 엔진 문제를 배제할 수 없다.
