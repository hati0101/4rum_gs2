# 프로그램 종료 응답 없음 진단

일반 최신 수정본은 `maps/release/GS2vF_ver139.w3x`다. 아래 맵은 원인을 좁히는 진단본이며 해결된 배포본이 아니다.

`GS2vF_ver140_exitdiag.w3x` — 인게임 제목 `가디언 스피리츠 II ver140 [종료진단]`.

사용자는 ver139 싱글플레이 중 바로 프로그램을 종료하면 응답 없음이 생긴다고 보고했다. GSRI는 초기화 시 번개 객체 768개와 64Hz 표시/8Hz 정보 갱신을 만든다. 종료 문제의 후보지만 원인으로 확인되지 않았다. 진단본은 GSRI 초기화만 생략해 사거리 표시/키/마우스/아이템 UI 이벤트 및 관련 객체를 만들지 않는다. 아이템 사거리 기능이 없는 것은 비교 목적이다. 전투 객체 데이터와 나머지 게임 함수는 보존했다. 팀 패널 등 다른 UI는 남아 있다.

ver139와 진단본을 같은 그래픽 설정, 영웅, 플레이 시간으로 비교한다. 직접 프로그램 종료 시 응답 없음 발생 여부와 멈춘 시간을 각각 기록한다. 가능하면 두 번씩 반복한다. 맵에서 메인 메뉴로 먼저 나온 뒤 프로그램을 종료하는 경로도 따로 비교한다.

진단본에서만 정상 종료되면 GSRI/관련 초기화와의 연관성을 좁힐 수 있지만, 이를 원인 확정이나 완전 해결로 해석하지 않는다. 둘 다 멈추면 다른 UI·리소스와 엔진 종료 경로를 추가 조사해야 한다. 싱글플레이에서 발생한다는 사실만으로 Warcraft 엔진 문제를 배제할 수 없다.

제공 환경에서는 Warcraft를 실행하지 못한다. 문법/타입 검사, 버전 제목, GSRI 초기화 생략, 다른 함수/자원 보존은 확인했으며 실제 종료 동작은 미검증이다. SHA256: `d8d8e4fc0952cef4b298f6b367133b7b2eba7b4eb53e6de49bd7ddd03a9ea1d1`.

## 정상 종료 ver137과 비교하기

사용자가 다시 첨부한 ver137은 최초 첨부본과 바이트 단위로 같으며, 같은 사거리 표시가 있어도 정상 종료된다고 보고했다. 그러므로 사거리 기능 존재 자체나 번개 객체 768개만으로 원인을 단정하지 않는다. ver137→139 사이의 변경을 각각 되돌려 비교한다.

- `GS2vF_ver141_range_compare.w3x`: ver139를 기반으로 GSRI 사거리 표시 코드를 정상 종료 ver137의 방식으로 되돌림. 사거리 표시는 유지되고, 새 동기화 조회 타이머는 실행되지 않는다. 나머지 최적화는 유지. 예전 로컬 능력 조회의 디싱크 위험도 돌아오므로 **싱글플레이 진단 전용**, 멀티플레이 배포 금지.
- `GS2vF_ver142_effects_compare.w3x`: ver139를 기반으로 d_effect의 이펙트 정리 두 함수만 ver137의 임시 트리거/PolledWait 방식으로 되돌림. 사거리 동기화와 나머지 최적화 유지. 해결본이 아니라 비교본이다.

같은 영웅/플레이 시간/종료 순서로 두 맵을 비교한다. 141에서만 정상 종료되면 GSRI 조회 변경을, 142에서만 정상 종료되면 이펙트 정리 변경을 우선 조사한다. 둘 다 멈추거나 둘 다 정상이면 추가 조합/다른 변경의 비교가 필요하다. 결과 한 번만으로 단일 원인을 확정하지 않는다.

각 맵의 인게임 제목은 ver141 [사거리조회 비교], ver142 [이펙트정리 비교]로 구분된다. 문법/타입 검사와 수정 대상 외 자원 보존은 확인했으나 실제 종료 동작은 미검증이다. 일반 최신 수정본은 여전히 ver139다.
