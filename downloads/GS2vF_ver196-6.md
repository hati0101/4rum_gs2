# GS2 196-6 패치노트

## 모든 영웅 특성창 선택

- 기존 F8·백틱 직접 선택 함수가 돌노부(HE15)만 처리하던 제한을 제거했습니다. 시노부·치즈코를 포함한 기존 영웅과 변신 영웅의 특성창 종류 79종을 공통 대상으로 등록했습니다. 사용하지 않는 보존용 종류도 목록에 포함됩니다.
- 기존 특성 아이콘 클릭·백틱(`)·F8이 자기 소유 특성창을 선택하는 같은 함수를 사용합니다. 키를 놓은 뒤 선택하고 다음 UI 갱신에서 한 번 더 선택을 보정합니다. 단축키 등록은 기존 F8/OEM_3 key-up을 유지합니다.
- 플레이어별 특성창을 동기화된 기존 틱에서 찾아 저장합니다. 새로운 투명 프레임이나 반복 타이머는 추가하지 않습니다. 특성창이 없거나 여러 개라 식별이 모호하면 선택을 바꾸지 않습니다.
- 실제 게임에서 native 아이콘 클릭 이벤트가 전달되는지, 키 입력과 선택 보정이 최종 선택을 유지하는지는 미검증입니다. 코드/모사 검증을 모든 영웅의 실제 게임 테스트로 해석하지 않습니다.

## 돌노부 — 겹겹의 암반

- 기존 최대 석갑 +2(10→12) 유지.
- 힘 +10, 최대 체력 +200 추가. 힘으로 얻는 체력180을 포함하면 합계 최대 체력 +380입니다.
- 특성 구매/완료 설명과 E의 [특성 적용] 설명을 갱신했습니다. 기존 ThickFur 아이콘·가격·조건·완료 표시·단축키 유지.
- 특성 상태 전환 때만 보너스를 지급합니다. 같은 상태로 툴팁을 다시 갱신해도 중복 지급하지 않습니다. 테스트 명령으로 특성을 해제할 때는 해당 보너스만 회수합니다.
- 기본 방어력과 민첩 성장, 다른 특성 및 QWER 수치는 바꾸지 않았습니다.

## 검증 및 보존

- 모사 검사 59개 통과: 등록된 특성창79종의 클릭/키 공통 경로,12개 플레이어 슬롯,다른 플레이어 입력 차단,변신/교체/제거/미존재/중복 특성창,스캔 재사용,힘·체력 중복 방지 및 테스트 해제,기존 치우 누수와 돌노부 전투 회귀 검사 포함.
- JASS 문법·타입·참조, MPQ 무결성·허용 변경·활성 파일 보존 검사 통과. 원본에 이미 있던 war3mapSkin.txt CRC 경고는 별도로 기록하고 보존합니다.
- 변경 내부 파일: war3map.j, war3map.wct, war3map.w3q(RE13 설명만), war3map.w3i(버전), (attributes). 유닛·능력·아이템 객체와 자산은196-5와 바이트 동일합니다.
- 치우 누수 정리/F9 안내/돌노부 지능 성장 형식 교정/196-5 투명 클릭 프레임 제거를 유지했습니다.
- 실제 Warcraft III·멀티플레이·에디터 재저장 테스트는 수행하지 않았습니다. 전원 멈춤 원인과 사이로스 선택 불가 원인도 미확정입니다.
