# GS2 196-4 패치노트

196-2 이후 요청한 수정들을 함께 포함한 파일입니다.

## 치우 — 블러드 스트라이크 누수 정리

- 패시브 판정 실패 시 남던 미사용 좌표 생성을 제거했습니다. 성공 분기의 관련 해제 코드도 정리했습니다.
- 피해·회복·발동 확률·확률 누적·대기시간은 유지했습니다. 에디터용 GUI 트리거에도 동일하게 반영했습니다.
- **8명 전원 게임 멈춤의 원인은 아직 미확정입니다. 이 누수 수정이 전원 멈춤을 해결했다고 검증한 것은 아닙니다.**

## F9 히든 영웅 안내

| 히든 | 조건 |
|---|---|
| 던 울프 · 렐리스 | 문 울프 1레벨, 게임 내 0~6시에 문 프로텍션(W) 사용 |
| 판다렌 듀얼 블레이더 · 시노부 | 스킬을 배우지 않은 기본 시노부가 철제 검 소지 상태로2레벨 달성, 남은 스킬 포인트2개 |

실제 변신 조건은 바꾸지 않았습니다.

## 돌노부 특성 아이콘 클릭

- 기존 메달 아이콘 위에 투명한 클릭 영역을 겹쳐 입력을 받도록 보강했습니다. 별도 아이콘 그림을 추가하지 않습니다.
- 클릭 직후 선택과 다음 UI 갱신에서의 선택 보정을 함께 처리합니다. 기존 native 버튼 처리에 선택이 덮이는 상황에 대응하는 구현이며, 이것이 제보의 확정 원인이라는 뜻은 아닙니다.
- 기본 영웅·다른 플레이어에게는 보이지 않으며, 자기 소유 특성 유닛만 선택합니다. F8·백틱은 유지합니다.

## 돌노부 지능 성장

- 지능 성장 값1.5는 유지하고 저장 형식 real(1)을 unreal(2)로 교정했습니다. 힘·민첩 성장 및 참고 UnitMetaData 형식과 맞춘 것입니다.
- 다른 능력치나 성장량을 바꾸거나 스크립트로 지능을 추가 지급하지 않았습니다. 형식 불일치는 확인했지만 이것이 실전 무성장의 원인인지는 게임 재확인이 필요합니다.

## 검증

- 최신 후보에 모사54개 통과. 치우 원본·수정본 각각12,000회 비교 포함: 비교한 피해·회복·발동 출력 동일, 수정본 좌표 잔여0.
- JASS 문법·타입·참조 검사(커뮤니티 API 헤더), MPQ 보존·허용 변경·CRC 검사 통과. 기존 war3mapSkin.txt CRC 경고 보존.
- 지능 성장 객체는 uinp 형식 태그1바이트만 변경됐으며 값1.5 및 나머지 객체/자산은 동일합니다.
- **실제 Warcraft III 클릭·레벨업·F9 화면·에디터 재저장·멀티플레이 안정성은 미검증입니다.**
