# GS2 196-8 — 돌노부 특성창 분류 교정 비교본

사용자가196-7에서도 돌노부 메달 클릭은 안 되고 백틱/F8은 된다고 재확인했습니다. 이전 클릭 보강은 실게임 해결로 인정하지 않습니다.

## 변경

- 기존 peon 특성창78종 모두 건물 분류(ubdg=1)인데 돌노부 nE15만 일반 유닛(ubdg=0)이던 차이를 확인했습니다. nE15도 기존 특성창과 같은 건물 분류로 맞췄습니다. 영웅 HE15가 아니라 숨겨진 특성창 유닛의 분류만 변경합니다.
-196-7에서 덧댄 메달 버튼 생성/기본 아이콘 숨김/앵커 갱신 호출을 제거하고196-6의 기존 native 아이콘 경로로 복귀했습니다. 남아 있는E1967 표시 함수/전역은 호출/생성되지 않는 보존 코드입니다.
- 모든 영웅 공통 백틱/F8 직접 선택과 다음 UI 갱신의 선택 보정 유지. 겹겹의 암반 최대 석갑+2·힘+10·최대 체력+200,치우 누수/F9 등 기존 변경 유지.
- 선택적 `-특성진단` 추가: 로컬 플레이어의 실제 특성창 종류/소유/건물·일꾼 분류,기본 아이콘 핸들,스크립트 클릭 콜백 횟수,선택 상태를 출력합니다. native 버튼의 기본 동작과 스크립트 콜백은 별개이므로 클릭 횟수0만으로 native 클릭 실패를 확정하지 않습니다. 입력 카운터/진단 값은 전투 판정에 사용하지 않습니다.

## 근거와 한계

분류 불일치는 확인했지만, 이것이 클릭 실패의 확정 원인인지는 실제 Warcraft에서 재확인이 필요합니다. 일반 유닛을 건물로 분류하면 native 선택/일꾼 목록/구조물 필터 등에 영향을 줄 수 있습니다. nE15는 원래 다른 특성창처럼 무적·공격 대상 없음·이동속도0·비충돌인 숨겨진 연구창이며 이 설정들은 그대로입니다. 다른78종과 분류를 맞춘 교정이지만 실제 게임 동작을 모사만으로 보장하지 않습니다.

## 검증

- 모사64개 통과. 기존78종과 분류 비교,단일 객체 필드/1바이트 변경,79종 공통 선택·12플레이어·중복 스탯 지급 방지·기존 전투 회귀·로컬 클릭 카운터·진단 출력 포함.
- JASS 문법/타입/참조 및 MPQ/허용 변경 검사 통과. 기존 원본war3mapSkin.txt CRC 경고 보존.
- 내부 변경j/wct/w3i/w3u/attributes. w3u는nE15 ubdg 값0→1 한 바이트만 변경. 스킬·특성·아이템 객체/자산 동일. 새 타이머/프레임/유닛 생성 없음.
- 런타임/WCT 변경 함수 동일. 실제 클릭·해상도·native 일꾼 선택·멀티 동기화·튕김 예방은 미검증.

클릭이 계속 안 되면,메달을 클릭한 뒤 `-특성진단` 출력2줄을 기록하면 프레임/선택/분류 상태를 구분할 수 있습니다.
