# GS2 196-3 패치노트

## 치우 — 블러드 스트라이크 누수 수정

- 패시브 판정에 실패할 때 남던 불필요한 좌표 객체 생성을 제거했습니다.
- 같은 좌표의 성공 분기 해제 코드도 함께 정리했습니다.
- 피해량·회복량·발동 확률·확률 누적·대기시간·트리거 활성화 동작은 유지합니다.
- 에디터용 GUI 트리거에서도 해당 생성/해제 동작만 비활성화했습니다.

**이 수정은 확인된 좌표 누수에 대한 조치입니다. 8명 전원 게임 멈춤의 원인이 확정되거나 해결된 것은 아닙니다.**

## 편의성 — F9 히든 영웅 안내

F9에 ‘히든 영웅 안내’를 추가했습니다. 실제 변신 조건은 바꾸지 않았습니다.

| 히든 | 변신 조건 |
|---|---|
| 던 울프 · 렐리스 | 문 울프 1레벨, 게임 내 0~6시에 문 프로텍션(W) 사용 |
| 판다렌 듀얼 블레이더 · 시노부 | 스킬을 배우지 않은 기본 시노부가 철제 검을 소지하고 2레벨 도달. 남은 스킬 포인트 2개 필요 |
| 플레임 비스트 · 리자드 | 썬더 비스트 1레벨에 화염의 정수 획득 |
| 판다렌 대지 수호자 · 시노부 | 기본 시노부 1레벨에 변화의 돌 획득 |

## 검증

- 196-2를 기준으로 제작했습니다. 돌노부와 다른 영웅·아이템의 수치 및 자산은 유지했습니다.
- 모사 45개·하네스 59개 통과. 모사에는 치우의 4개 스킬 레벨과 성공/실패/혼합 패턴을 원본·수정본 각각 12,000회 실행한 비교가 포함됩니다. 수정본 좌표 잔여 0개이며 비교한 전투 출력은 동일했습니다.
- 전체 JASS 문법·타입·참조 검사(커뮤니티 API 헤더), MPQ 보존·허용 변경 검사 통과. 기존 war3mapSkin.txt CRC 경고는 보존했습니다.
- **실제 Warcraft III 게임 실행·F9 화면·에디터 재저장·8인 멀티플레이 안정성은 아직 미검증입니다.**
