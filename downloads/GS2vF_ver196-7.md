# GS2 196-7 — 돌노부 특성 아이콘 클릭 보강

196-6에서 돌노부 변신 후 백틱/F8은 되지만 아이콘 클릭이 안 된다는 제보에 대응한 후보입니다.

- 돌노부일 때만 기본 일꾼 아이콘 위치에 명시적 클릭 이벤트가 있는 메달 버튼을 표시합니다. 기본 아이콘을 가려 하나만 보이도록 합니다.
- 버튼은 중심점 하나에 고정 크기0.032×0.032를 지정합니다.196-4의native bounds 전체를 물려받는 투명 클릭 프레임을 재사용하지 않습니다. 프레임 전체 영역이 클릭을 가로채지 않도록 구현상 범위를 고정했습니다. 실제 해상도/종횡비별 배치는 게임 확인이 필요합니다.
- 기본 아이콘을 찾지 못하거나 자기 돌노부 특성창을 확인하지 못하면 새 버튼을 숨깁니다. 다른 영웅으로 바뀌면 기본 아이콘의 이전 표시 상태를 복원합니다.
- 클릭은196-6의 공통 특성창 선택을 사용하고 다음 UI 갱신에서 한 번 더 선택을 보정합니다. 백틱/F8,다른 영웅의 공통 선택은 유지합니다.
- 프레임은 모든 클라이언트에서 초기화 때 한 번 생성하고 표시/선택만 로컬 처리합니다. 새 반복 타이머·로컬 유닛 생성은 없습니다.
- 겹겹의 암반 최대 석갑+2·힘+10·최대 체력+200과 치우 누수/F9 등 기존 수정은 유지합니다.

## 검증

모사 검사64개, JASS 문법·타입·참조, MPQ/허용 변경 검사 통과. 버튼 크기·단일 중심 앵커·소유자·표시/복원·클릭 후 선택 경로를 모사했습니다. 유닛·능력·아이템·특성 객체/자산은196-6과 바이트 동일합니다. 내부 변경은j/wct/w3i/attributes뿐입니다.

실제 Warcraft III에서의 클릭·표시·F1선택·해상도·메뉴 중 표시·멀티 동기화는 미검증입니다. native 기본 버튼 이벤트가 전달되지 않는 정확한 엔진 원인까지 재현한 것은 아닙니다.
