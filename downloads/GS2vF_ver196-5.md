# GS2 196-5 — 선택 불가 제보 비교본

196-4에서 사이로스가 생성됐으나 클릭·F1 선택이 안 됐다는 제보에 대응한 비교용 버전입니다. 원인이나 해결을 실제 게임에서 확인한 버전은 아닙니다.

- 196-4에서 추가한 돌노부 특성 아이콘 위의 투명 클릭 프레임을 제거했습니다. 해당 프레임이 원인이라고 확정하지 않습니다.
- 기존 아이콘 이벤트와 클릭 후 선택 보정, F8·백틱 방식은 유지합니다. 아이콘 클릭의 실제 작동은 재확인이 필요합니다.
- 사이로스 객체, 랜덤 배정 코드, 다른 영웅·아이템·자산은 196-4와 동일합니다.
- 치우 미사용 좌표 누수 정리, F9 히든 안내, 돌노부 지능 성장 형식 교정은 유지합니다.

## 자동 검증

모사 검사 54개 통과. JASS 문법·타입·참조 및 MPQ 보존/허용 변경 검증 통과. 기존 내부 CRC 경고는 검증 기록에서 구분합니다. 객체/자산은 196-4와 바이트 동일하며 수정 함수는 ESC_IconInit 및 E1964_Refresh입니다. 나머지 스크립트 차이는 버전 문구입니다. 런타임 및 에디터 스크립트에 같은 변경을 적용했습니다.

## 실제 게임 확인 필요

사이로스 랜덤 배정 직후 클릭·F1 선택, 다른 영웅 선택, 돌노부 특성창 클릭/F8/백틱을 확인해야 합니다. 실제 Warcraft III 실행 테스트는 수행하지 않았습니다. 전원 멈춤 해결 여부도 미검증입니다.
