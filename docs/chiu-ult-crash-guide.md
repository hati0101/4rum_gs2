# 치우(퓨리 파이터) 궁극기 "레쓰 오브 블러드" 튕김 검토 및 최적화 가이드

- 대상: 다크니스 `Nbbc` 퓨리 파이터(치우), 궁극기 `A0U5` 레쓰 오브 블러드
- 증상: 궁극기 사용 중 가끔 게임이 튕김
- 기준 맵: `maps/GS2vF_ver19_fixed.w3x` (ver19)
- 작성: 2026-09-29, 맵 데이터·스크립트·설치된 게임 원본 데이터(3.0.0.24268) 분석 기준

> 튕김 현장의 크래시 로그는 아직 없음. 아래 원인은 코드와 데이터로 확인한 "부하 원인"이며,
> 가장 유력한 순서로 정리함. 튕김이 다시 나면 5장의 방법으로 로그를 모아 확정할 것.

---

## 1. 요약

궁극기 한 번에 **아래 일이 거의 한 순간(약 0.5초 안)에 몰려서** 일어난다.

| 항목 | 궁 1회 기준 | 비고 |
|---|---|---|
| 착탄(인페르노) | **45회**, 거의 동시 | 설명은 "4.5초간 최대 45번"이지만 실제 분산 시간 0.1초 |
| 소환되는 폭풍 유닛 `e00N` | **45개** (각 1초 유지) | 모델 `BloodTornado.mdl`: 파티클 이미터 13개, 폭풍 1개당 입자 약 150개 → 동시 최대 약 **6,700개** |
| 새 유닛 진입 시 실행되는 트리거 | 46개 유닛 × 48개 = **약 2,200회** | 맵 전체 진입 이벤트 트리거 48개 |
| 새로 쌓이는 피해 이벤트 등록 | 46개 유닛 × 58개 = **약 2,700개** | `Unit Detection`이 조건 없이 등록, **게임 끝까지 안 지워짐** |
| 착탄 피해 1건마다 조건 검사 | 대상 1명당 최소 58개 | 적 10명 × 45회면 약 **26,000회** |

→ **순간 부하가 매우 큼** + **게임이 길어질수록 이벤트 등록이 계속 쌓임**.
사양이 낮거나 게임 후반일수록 멈춤 → 튕김(끊김) 가능성이 커지는 구조. "가끔"이라는 증상과도 맞음.

## 2. 현재 구현

```
[치우] A0U5 시전 (별똥별 기반 채널링 4.5초, "stand spin" 애니메이션)
  └ 트리거 "Wrath of Blood"
      ├ 치우 패시브 Blood Strike 트리거 3개 끔 (회전 공격에 반응 안 하게)
      ├ 더미 e00O 생성 → A0CH(레인 오브 카오스 기반) "rainofchaos" 시전
      │     A0CH: 반경 450, 생성 수 45, 지속시간 0.1초  ← 45개가 0.1초 안에 전부 시전됨
      │     └ 착탄마다 A0CI/J/K(인페르노 기반, 레벨별) 시전
      │           0.5초(착탄 지연) 뒤 반경 275 피해(50/70/90) + 0.15초 기절
      │           소환 유닛 e00N(BloodTornado.mdl, 무적·선택불가) 1초 유지
      ├ 0.1초마다 치우의 현재 명령 확인 (채널 끝날 때까지 대기)
      └ 채널 끝나면 Blood Strike 켜고 더미 KillUnit
```

관련 오브젝트

| ID | 기반 | 역할 |
|---|---|---|
| `A0U5` | 별똥별 `AEsf` | 치우 궁극기 (채널링 껍데기) |
| `e00O` | 위습 | 레인 오브 카오스를 대신 쓰는 더미 (`Avul`, `A0CH`) |
| `A0CH` | 레인 오브 카오스 `ANr3` | 45회 착탄, 지속시간 0.1초 (원본값 1초) |
| `A0CI` / `A0CJ` / `A0CK` | 인페르노 `ANin` | 궁 1/2/3레벨용 착탄 (피해 50/70/90) |
| `e00N` | 위습 | 착탄마다 소환되는 폭풍 연출 유닛 (`Aloc`, `Avul`) |

## 3. 발견된 문제 (우선순위 순)

### P1. 45회 착탄이 한 순간에 몰림
- `A0CH`의 지속시간(`adur`)이 **0.1초**라서 45회가 거의 동시에 시전되고, 0.5초 뒤 거의 동시에 떨어진다.
  (게임 원본 레인 오브 카오스는 지속시간 1초에 2개)
- 같은 순간에 폭풍 유닛 45개 생성, 착탄 피해 45회 × 범위 내 대상 수만큼 피해 이벤트 발생.
- 툴팁의 "4.5초 동안 최대 45번"과 실제 동작이 다름.
- 단, **이 순간 몰아치는 폭딜이 스킬의 핵심**이다. 착탄 위치는 반경 450 안 무작위라 위치별 기대 피해는 아래와 같다
  (시뮬레이션 2만 회 평균).

  | 중심에서 거리 | 평균 적중 | 1 / 2 / 3레벨 피해 |
  |---|---|---|
  | 0 ~ 150 | 약 17회 | 약 840 / 1,170 / 1,510 |
  | 300 | 약 13회 | 약 650 / 910 / 1,180 |
  | 450 (가장자리) | 약 7회 | 약 370 / 510 / 660 |

  기절은 착탄마다 0.15초지만 거의 동시에 떨어지므로 실제로는 한 번(약 0.15초)만 걸린다.

### P1. `Unit Detection`이 모든 유닛을 피해 트리거 58개에 등록 (누적)
- 이벤트: 맵 전체 진입, **조건 없음**. 새로 들어오는 **모든 유닛**(크립, 라인 유닛, 더미, 연출 유닛)을 피해 트리거 58개에 등록한다.
- 등록은 게임이 끝날 때까지 지워지지 않는다. 궁 1회에 약 2,700개, 크립/라인 웨이브마다 계속 쌓임.
- 궁에서 나오는 `e00N`은 **무적 + 선택 불가(로커스트)**라 피해를 받을 일이 없는데도 58개씩 등록됨 → 순수 낭비.
- 피해가 날 때마다 대상에 등록된 트리거 58개의 조건을 전부 검사하므로, 착탄 45회가 몰리는 궁극기에서 특히 무거움.

### P2. 폭풍 모델 `BloodTornado.mdl`이 무겁고 텍스처가 빠짐
- 클래식 형식(MDX 800) 임포트 모델, 파티클 이미터 **13개**(각 초당 10개, 수명 1~2초).
- 참조 텍스처 중 게임에 **없는 파일**:
  - `ReplaceableTextures\Weather\Clouds8x8.blp` — 현재 게임에 SD/HD 모두 없음
  - `Textures\Ghost2.blp`, `Textures\WaterBlobs1.blp` — HD에만 있고 **클래식(SD) 그래픽에는 없음**
- 텍스처가 없으면 대체 텍스처로 그려지지만, 45개가 동시에 뜨는 상황에서는 불필요한 부담 + 그래픽 설정에 따라 문제 소지.

### P3. 그 밖의 작은 문제
- **더미 수명**: 더미 `e00O`에 만료 타이머가 없고, 트리거가 끝날 때 `KillUnit`만 함. 트리거가 중간에 끊기면 더미가 남음.
- **위치 누수**: `GetUnitLoc(...)`을 매번 새로 만들고 지우지 않음 (궁 1회당 몇 개 수준, 치명적이진 않음).
- **특성 버그** (`Wrath of Blood sp`): 반마법 보호막 더미를 만들고 `A0KM` 레벨을 **더미가 아니라 치우에게** 설정함
  (`SetUnitAbilityLevelSwapped('A0KM', GetTriggerUnit(), 2)`) → 레벨 2가 적용되지 않음. 튕김과는 무관.

## 4. 최적화 가이드

### 방향: 순간 폭딜(동작)은 그대로, 부하만 줄이기

착탄을 시간에 나눠 떨어뜨리는 방법(`A0CH` 지속시간 0.1 → 4초)은 **쓰지 않는다.**
- 폭딜이 4초에 걸친 지속 피해로 바뀌고, 적이 범위를 빠져나갈 수 있음
- 0.15초 기절이 약 0.09초 간격으로 계속 걸려 **범위 안 4초 기절 고정**이 됨 → 스킬 성격 자체가 바뀜

대신 아래 방안 중에서 고른다.

| 방안 | 내용 | 게임 동작 | 부하 감소 | 작업 |
|---|---|---|---|---|
| **A. 낭비 제거** | `Unit Detection` 조건 추가(단계 2-1) + 폭풍 모델 경량화/텍스처 수정 | 그대로 | 등록 누적 제거, 입자 부담 감소 (착탄 45회·피해 이벤트 수는 그대로) | 트리거 1개 + 모델 |
| **B. 착탄 계산을 트리거로 (추천)** | 착탄 45회를 실제로 떨어뜨리지 않고, 시전 0.5초 뒤 무작위 착탄 45개를 **계산만** 해서 대상마다 맞은 횟수 × 피해를 **한 번에** 주고 기절 1회. 연출은 가벼운 이펙트 10개 정도 | 그대로 (위치별 기대 피해·분포 동일, 기절 1회) | 유닛 생성 45개 → 0, 피해 이벤트 45×대상 수 → 대상 수만큼, 입자 대폭 감소 | 트리거 재작성 (JASS) |
| C. 착탄 수 줄이고 피해 올리기 | 45회 → 15회, 피해 3배 | 평균 피해 같음, 대신 운에 따른 편차 커짐 | 약 1/3 | 데이터만 |

추천 순서: **A는 무조건** (다른 스킬에도 효과가 있음) → 튕김이 계속되면 **B**.

방안 B 세부
- 착탄 판정: 반경 450 안 무작위 점 45개 → 각 적마다 275 안에 든 점 개수 세기 (지금과 같은 확률 분포)
- 피해: 개수 × 50/70/90을 한 번에. 피해 종류는 기존 인페르노와 같게 맞추고 인게임에서 비교 확인
- 기절: 한 번 이상 맞은 적에게 0.15초 기절 1회 (기존 더미 스톰볼트 방식 재사용)
- 연출: 무작위 위치 10개 정도에 폭풍 이펙트만 잠깐 (유닛 아님)
- 채널 중 끊기면: 기존과 같게 0.5초 전이면 착탄 없음

### 단계 2 — 트리거 수정 (월드 에디터에서)

1. **`Unit Detection`에 조건 추가** — 피해를 받을 일 없는 유닛은 등록하지 않기
   - 예: `(Triggering unit)의 로커스트('Aloc') 레벨 = 0` **그리고** `유닛 타입 ≠ 위습` **그리고** 더미 유닛 타입(`e0xx` 연출/더미) 제외
   - 궁 1회 등록 2,700개 → 거의 0. 다른 스킬의 더미들도 같이 줄어듦.
2. **`Wrath of Blood` 더미 수명**: 더미 생성 직후 `만료 타이머 6초` 추가 (트리거가 끊겨도 자동 제거). 채널 끝의 `KillUnit`은 유지.
3. **위치 누수**: `GetUnitLoc` 결과를 변수에 담아 쓰고 `RemoveLocation`.
4. **특성 버그**: `Wrath of Blood sp`의 `A0KM` 레벨 설정 대상을 `(Last created unit)`으로.

### 단계 3 — 구조 개선 (장기)

- 유닛별 피해 이벤트 등록(`Unit Detection`, `Set Damage Trigger Event`) 대신,
  리포지드(1.31+)의 **"일반 유닛 이벤트 - 유닛이 피해를 받음"** 한 번 등록으로 전환.
- 58개 트리거의 **이벤트만** 바꾸면 되고 조건·동작은 그대로. 등록 누적 자체가 사라짐.
- 트리거 수가 많아 한 번에 바꾸면 위험하므로, 자주 쓰이는 것부터 나눠서 전환 + 매번 테스트.

## 5. 검증 방법

### 재현
1. 테스트 맵에서 치우 선택, 레벨 업 후 궁극기 습득.
2. `-gstest`로 아군 봇, 크립/라인 유닛이 많은 곳(적 다수)에서 궁 반복 사용.
3. 게임 후반을 흉내 내려면 20~30분 이상 진행한 뒤 사용 (등록 누적 확인).

### 비교 지표
- 궁 사용 순간의 끊김(프레임 드랍), 튕김 여부
- 방안 적용 전후로 **같은 위치의 적이 받는 피해**가 3장 표와 비슷한지 (중심 1레벨 약 840), 기절이 한 번만 걸리는지

### 튕겼을 때 모을 것
- `문서\Warcraft III\Errors\<날짜 시간>\Crash.txt` (+ `War3.dmp`)
- `문서\Warcraft III\Logs\War3Log.txt` (게임을 끈 뒤에 기록됨)
- 사용 시점, 그래픽 설정(클래식/리포지드), 게임 경과 시간, 궁 레벨, 주변 유닛 수
