# 195-11 특성 점검과 195-12 교전 멈춤 비교본

## 제보와 확정하지 못한 부분

사용자는 **195-9**, 갱 교전 중 **화면과 프로그램 전체가 멈춤**을 보고했습니다. 참여 영웅으로 **소엔(드로우 어쎄신)**, **불리자드(플레임 비스트)**를 기억하며 다른 영웅/정확한 스킬은 불명입니다. 신타는 이전에 이미 고친 상태라고 정정했고, 레인저 지속 피해는 정상 작동을 확인했습니다. 따라서 신타와 레인저를 다시 수정하지 않습니다.

**이번 정적/모사 검사로 이 멈춤을 재현하거나 원인을 확정하지 못했습니다.** 195-10 투마 수정은 195-9에서 발생한 해당 사건의 원인이 될 수 없지만, 195-9의 최적화 변경은 원인 후보에서 배제하지 않았습니다. 아래 능력 설정 보강은 멈춤을 해결했다는 증거가 아닙니다.

## 내가 넣은 195-9 변경의 재검토

- 보존된 실제 195-8과 195-9를 다시 비교하고, 저장된 당시 패치를 재실행한 결과가 195-9 런타임과 바이트 단위로 같은지 확인했습니다. 기록 밖의 런타임 수정은 발견되지 않았습니다.
- 195-9에서 바뀐 활성 파일은 스크립트·에디터 스크립트·맵 이름·CRC 속성뿐입니다. 객체/리소스는 당시 비교와 같이 보존됩니다. 구체 목록은 `own-change-audit.json`과 이전 `reviews/ver195-9/script.diff`에 있습니다.
- 플레임 비스트의 범위 피해/스킬/피격 패시브/피해 감소, 소엔의 백스탭/추가 피해/궁극기 핵심 함수는 195-8과 195-9에서 같습니다. 소엔의 처치 후 처리에는 시작 위치의 임시 객체 해제 1곳이 들어갔으므로, 해당 영웅과 관련된 변경이 전혀 없었다고 표현하지 않습니다.
- 기존 플레임 비스트 패시브는 범위 피해 전에 4초 재발동 시간을 기록하고, 기존 소엔 백스탭은 추가 피해 전에 발동 대기 상태를 해제합니다. 실제 함수를 모사해 이 두 재진입 방어의 순서를 확인했습니다. 다른 영웅·아이템·네이티브 이벤트를 포함한 실제 교전 전체를 재현한 검사는 아닙니다.
- 195-9의 위치 객체 해제·그룹 소유권·원샷 타이머 정리·UI 캐시를 재검토했으나 이번 멈춤의 결정적인 증거는 발견하지 못했습니다. **따라서 진단용 비교본은 195-9 런타임 변경 전부를 제거한 195-8 기준으로 별도 제작했습니다.**

## 전체 특성 연결 점검의 범위

- 현 런타임 함수 4,976개에서 특성 연구와 능력 레벨 선택을 추적했습니다. 연구가 포함된 함수의 능력 레벨 설정 80곳/서로 다른 능력 67개를 자동 추출해 조사했습니다. `trait-level-audit.json`은 예비 분류 결과이며, 동적인 함수 인자·복합 분기까지 자동으로 올바름을 증명한 자료는 아닙니다.
- 현재 능력/스킨/영웅/특성/아이템 객체의 실수 필드에서 NaN/무한대 값을 발견하지 못했습니다.
- 명시적 0초 반복 타이머, exitwhen/return이 아예 없는 loop, 삭제된 봇 함수의 문자열 호출 잔재를 발견하지 못했습니다. 함수/TriggerExecute 정적 호출 그래프에서 찾은 직접 순환은 기존 정령 포인트 갱신의 8/15초 대기 후 재호출입니다. 네이티브 피해·명령·지역 이벤트로 생기는 동적 순환까지 부재를 증명하지는 못합니다.
- 기존 공장 기반 능력들의 생성 주기를 확인했습니다. 과거 피와케 포켓 봄버의 86400초 주기/10초 수명 설정은 유지됩니다. 공장/소환 능력을 일괄 재작성하지 않았습니다.
- 봇 삭제 때 없어진 연구 완료 핸들러는 봇 분류/활성 상태 조건으로 봇의 연구 대화 상태만 정리하는 코드였습니다. 사람 영웅 특성 효과를 그 함수에서 전부 처리하던 구조라는 증거는 찾지 못했습니다. 삭제된 봇을 복원하지 않았습니다.

## 195-11의 변경 — 보조 능력 마나만 명시

아래 13개는 기본 구간에 이미 마나 0이 명시돼 있지만 일부 레벨이 기본값을 물려받습니다. **그 13개 모두 동일한 마나 필드 구성이 최초 F8에도 있습니다**(`f8-cost-comparison.json`). “봇 추가로 새로 고장난 13개 스킬”이나 “실전 고장 13건을 재현해 해결했다”고 주장하지 않습니다. 누락된 값에 의존하지 않도록 정리하는 제한된 보강입니다.

| 내부 능력 | 용도 |
|---|---|
| A0XP | 나이트 차지의 폭발 |
| A009 | 글레이브 효과 |
| A01O | 스워시 슬라이드의 스턴 |
| A00J | 스트라이크 폭발 |
| A0KS | 벤데타 효과 |
| A0DD / A0DF | 카운터 스펠의 스턴/침묵 |
| A041 | 매니스 크라이 효과 |
| A0EQ | 블로우 붐 침묵 |
| A0IM | 술병 투척 보조 효과 |
| A0XR | 그랜드 판타즘 폭발 |
| A08X | 아케인 애로우 보조 효과 |
| A011 | 브레인 쇼크 보조 효과 |

기본/스킨 양쪽에서 이 보조 능력들의 선언된 전 레벨 마나를 0으로 명시합니다. **피해·회복·감속·기절/침묵 시간·대상·범위·쿨다운·발동 확률·영웅 시전 마나는 변경하지 않았습니다.** 기존 명시 비용이 70/80/100 등인 능력은 비용을 없애지 않았습니다. 레인저와 신타, 나머지 영웅 스킬은 제외했습니다.

195-11 런타임은 195-10과 **버전 안내 문구 외 동일**합니다. 새로운 피해 이벤트/타이머/후처리 코드를 추가하지 않았습니다. 195-10의 투마 내부 능력 마나 0·범위 300 설정도 유지합니다. 아이템 구매·조합/재료·재고, 사거리 표시, 스킨과 복구 자료는 보존합니다.

## 비교본 195-12 사용 목적

- 파일: `maps/diagnostics/GS2vF_ver195-12_compare1958.w3x`
- 인게임 제목: **가디언 스피리츠 II 195-12 비교본**
- 실행 코드: **195-8과 버전 문구 외 바이트 동일**. 즉 내가 195-9에서 넣은 코드 변경 전부를 제외했습니다. 195-8의 봇 삭제와 기존 피해 추적 분산은 그대로입니다.
- 능력·유닛·아이템·특성·문자열 데이터는 정식 195-11과 같습니다. 투마 보강과 이번 보조 마나 보강은 양쪽에 똑같이 들어 있습니다. 따라서 비교 중 수치/구매/조합 차이를 만들지 않습니다.
- 이 비교본은 195-9의 누수/UI 비용 보강을 되돌리므로 장시간 성능 면에서 불리할 수 있습니다. 원인 분리용이며 더 안정적이거나 멈춤이 해결됐다고 검증된 버전이 아닙니다.

같은 영웅/특성/아이템 조합으로 정식과 비교본을 별도 플레이해 기록해야 합니다. 한 판 무증상이라는 사실만으로 원인을 확정하거나 해결됐다고 볼 수 없습니다. 기존 `-성능` 출력은 유지하지만 이것만으로 클라이언트 전체 멈춤의 원인을 알 수는 없습니다. 재현 리플레이, 정확한 스킬 순서, 멈춘 경과 시간과 가능하면 게임 로그가 필요합니다. 멈춘 뒤 생긴 리플레이는 정상 저장되지 않았을 수도 있습니다.

## 검증과 한계

- 정식/비교본을 각각 전체 JASS 문법 검사했습니다(두 맵을 한 프로그램으로 합쳐 검사하지 않음).
- 실제 런타임/객체로 소엔·플레임 비스트 기존 재진입 방어 모사, 13개 비용 필드 외 다른 능력 필드 보존, 신타·레인저/아이템/특성 객체 보존을 확인했습니다.
- 두 파일 모두 활성 1,069개 MPQ 항목과 에디터 코드 903개 블록 길이를 검증했습니다. 변경 파일 CRC와 MPQ 정리 전후 파일 내용도 대조했습니다. 활성 리소스는 삭제하지 않았습니다.
- 정상본과 비교본의 능력 객체 파일은 바이트 동일합니다. 각 맵의 SHA256·바이트 수·모든 변경 필드는 `verification.json`에 있습니다.
- 실제 Warcraft/월드 에디터 재저장/멀티플레이 교전은 실행하지 못했습니다. **교전 멈춤은 원인 미확정 상태로 남습니다.**
