# 195-10 — 투마 플레임 버스트 내부 폭발 능력 설정 보강

사용자 제보: 투마(플레임 블레이더)의 플레임 버스트가 작동하지 않으며 특성을 찍어도 작동하지 않음. 레인저 지속 피해도 추가 제보됐으나, 사용자가 다시 확인한 결과 정상이라고 정정하여 레인저는 수정하지 않았습니다.

## 조사 결과

- 시전 능력 A0CP(Absk), 내부 폭발 A0CV(AHtc), 더미 h00W(hfoo), 특성 R048(화염의 구속)입니다.
- 기존 트리거는 `A0CP 레벨 + 4 × R048 연구 수`로 더미 A0CV 레벨을 고르고 thunderclap을 시전합니다. 정상 구간 1~4, 특성 구간 5~8입니다.
- 195-7·195-8·195-9에서 해당 트리거 본문과 A0CV 데이터가 동일합니다. 195-9 최적화 때 변경된 부분은 아닙니다.
- A0CV의 마나 소모 0은 1~4레벨에만 명시되고 5~8레벨에는 없습니다. h00W에는 별도 마나 설정이 없어 footman 기반 기본값에 의존합니다. 마나 없는 더미가 기본 능력의 비영(非零) 마나 비용을 물려받으면 내부 시전이 실패할 수 있습니다.
- A0CV의 효과 범위도 1~2레벨에 명시되지 않았습니다. 맵의 원본 AHtc 자체는 1레벨/범위 10으로 별도 변경되어 있습니다. 기본값 및 레벨 확장 해석에 의존하지 않도록 툴팁 값 300을 명시할 필요가 있습니다.
- 이 환경에서 실제 Warcraft 엔진을 실행하지 않았으므로, 위 누락이 실제 제보의 유일한 원인이라고 확정한 것은 아닙니다.

## 수정

A0CV 하나만 대상으로 기본/스킨 객체 양쪽의 1~8레벨에 다음 두 필드를 명시했습니다.

- `amcs`(마나 소모): 0
- `aare`(효과 범위): 300

스킬 시전 트리거, 더미 종류/3초 수명, 영웅 마나 75/90/105/120, 쿨다운 12초, 공격속도 효과 5초, 초기 피해 40/80/120/160 및 특성 +100, 감속 15/20/25/30% 및 특성 +50%p, 감속 시간 1.5초는 유지합니다. 다른 누락 필드를 일괄 수정하거나 별도 피해 트리거를 추가하지 않았습니다. 전역 원본 AHtc도 수정하지 않았습니다.

런타임 코드는 195-9 → 195-10 버전 안내 변경만 있습니다. 그 외 런타임 본문은 바이트 대조로 같습니다. 레인저, 아이템 구매·조합, 사거리 표시, 다른 스킬과 특성은 그대로입니다. 기존 195-9 최적화와 봇 삭제, 드래곤 워리어 등 복구 자료도 유지합니다.

## 검증

- 전체 JASS 문법 검사 통과.
- 실제 Flame Burst 트리거를 추출해 모사 실행: 스킬 1~4레벨 × 특성 전후 총 8가지의 내부 레벨, 명령, 마나 비용 0, 범위 300, 피해/감속/지속시간 보존 검사 통과. 엔진 시전 성공이나 실제 피해를 측정한 검사는 아닙니다.
- A0CV의 amcs/aare 외 모든 능력 필드·다른 능력 객체가 동일한지 대조했습니다. 유닛/아이템/특성/문자열 파일도 바이트 동일합니다.
- 전체 1,069개 활성 MPQ 항목 유지. 실질 변경은 war3map.j / war3map.w3i / war3map.w3a / war3mapSkin.w3a / CRC 속성의 5개 파일입니다. 나머지 1,064개는 압축 해제한 내용이 같습니다. WCT는 블록 길이를 재검사했고 변경할 버전 문자열이 없어 내용이 같습니다.
- 교체된 MPQ payload/테이블 잔여 공간만 정리하고, 정리 전후 모든 활성 파일 내용 및 변경 파일 CRC를 검증했습니다.

현재 맵은 **GS2vF_ver195-10.w3x**, 인게임 제목은 **가디언 스피리츠 II 195-10**입니다. 상세 크기/SHA256은 verification.json에 기록했습니다. 실제 게임에서는 특성 전후 모두 적 생체 지상 유닛을 300 범위 안에 놓고, 공격속도 버프와 별도로 폭발 피해·감속이 들어가는지 확인해야 합니다. 여전히 재현되면 당시 레벨과 특성, 영상/리플레이로 발동 이벤트/더미 명령 실패를 추가 조사해야 합니다.
