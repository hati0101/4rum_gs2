# ver144 — 카이 쿨다운 / 성역 / 바람의 부츠

기준 ver143, 결과 `maps/release/GS2vF_ver144.w3x` (인게임 ver144). 드래곤 워리어·기존 리소스 보존. 새 파일 크기 8,912,640바이트. MPQ 교체 잔여 공간 정리 후 활성 파일 1,068개를 모두 읽어 압축 해제 내용 일치 확인.

## 카이 바람의 악령

A0EA는 20초 쿨다운/3초 은신/20% 이속 증가/50 추가 피해다. 기존 GS117 은신 쿨다운 보정에 등록돼 있었으나 표시용 Channel 프록시가 없었다. 다른 은신기의 방식처럼 독립 ZW58 프록시를 추가하고 GS125_WindProxy에 연결했다. 시전 시부터 기존 20초 기한이 적용되도록 하며, 특성/마나/효과 수치는 보존했다.

## 바스테트 성역

A0JL 즉시 시전 후 스크립트가 GetSpellTargetUnit의 위치를 쓰던 것을 시전자 위치로 바꿨다. A0JM의 대상에 invulnerable을 추가했다. 무적이 된 아군을 대상에서 제외하는 설정을 제거해 이미 무적 상태인 동안에도 유지 대상으로 삼는다. 범위는 툴팁의 800으로 명시했다. 1/2/3레벨 2/3/4초는 유지하며 더미 및 마법진 수명을 그 지속시간과 맞췄다. 실제 네이티브 voodoo의 연속 무적은 게임에서 확인해야 한다.

## 바람의 부츠

기존 A056은 ANwk 계열로 -10%를 저장했지만 영웅 Wind Walk와 주문/처리가 간섭할 여지가 있었다. 아이템 A056의 베이스를 AIin(아이템 투명화)으로 분리하고, 고유 투명화 버프 BW44를 배정했다. 7초/60초 쿨다운/100 마나는 기존 수치다. I01G의 기본 +60 이동속도, +6 민첩 및 아이템 선언은 변경하지 않았다.

- 감속은 자기 자신에게만 적용하는 SW44(-10% 이동속도, 공격속도 변화 0)와 고유 BW45로 처리. 투명화 종료/공격/사망/시간 만료/효과 미적용 시 정리.
- 기습 피해 100은 아이템 사용 후 첫 공격의 실제 물리 공격 피해 이벤트에 한 번 가산. 원거리 공격의 투사체 도착을 위해 목표와 짧은 대기 기한을 보관하며 3초가 지나면 정리한다. 취소된 공격/늦게 도착하는 투사체의 실제 게임 동작은 추가 확인이 필요하다.
- 부츠 코드에서 영웅 은신기 쿨다운을 시작/리셋하지 않음. 기존 GS117 은신 코드에 부츠를 등록하지 않는다.
- 특수 아이템 네이티브/오라와 각 영웅 은신기 조합은 실제 엔진 테스트가 필요하다. 코드/객체 검증만으로 인게임 수정 완료를 보증하지 않는다.

## 검증

전체 JASS 문법/타입 검사 통과. 수정 대상 2개 능력(A056/A0JM) 외 기존 능력 데이터 동일. ZW58/SW44 능력과 BW44/BW45 버프만 추가. 기존 유닛·아이템·특성 데이터 바이트 동일.

모사 타이머 검사: 한 번의 +100 가산, 자연 7초 만료, 버프 적용 실패, 다른 쿨다운 상태 보존, 잔여 저장소/타이머 0 확인. 모사 검사는 실제 Warcraft 네이티브를 실행하지 않는다. 실제 엔진, 멀티플레이, 월드 에디터 전체 재저장은 미검증이다. 일부 기존 런타임 확장이 에디터 헤더에 없기 때문에 재저장 결과는 별도 확인해야 한다. 신규 부츠 모듈은 에디터 헤더에 initializer library로 포함했다.

싱글 테스트 후 멀티플레이: 카이 D 시전 직후/은신 끝/기습 직후 쿨다운 기한 확인, 성역 3레벨 안에서 반복 공격을 받아 4초 동안 연속 보호되는지 확인, 바람의 부츠 사용 전후 실제 이동속도와 각 영웅의 은신 쿨다운을 비교, 근접/원거리 기습 피해가 한 번만 추가되는지 확인.
