# ver145 — 바람의 부츠 소환 회귀 수정

ver144에서 A056의 기본 능력을 AIin으로 잘못 지정했다. AIin은 인퍼널 소환 원본이며 내부 구현은 AUin이다. 따라서 부츠 사용 시 소환이 발생했다. 코드/모사 검사만으로 이 기본 능력 선택 오류를 검출하지 못했다.

추출된 Warcraft 기본 데이터(w3x2lni의 zhCN-1.32.8 ability.ini)에서 AIv1의 내부 코드가 AIvi, 기본 버프가 Binv인 실제 아이템 투명화임을 확인했다. A056의 기본 원본 ID를 기본/스킨 데이터 양쪽에서 AIv1으로 바로잡았다. AIvi는 구현 코드이며 해당 기본 객체의 ID는 AIv1이다.

사용자 의도는 10% 감속하는 윈드워크 효과다. ver144의 7초 투명화·10% 감속·첫 공격 기습 피해 100·60초 쿨다운·100 마나와 고유 처리/버프는 유지한다. 영웅 Wind Walk와 분리하는 기존 방식도 유지한다. 구현은 네이티브 아이템 투명화와 고유 감속/기습 처리 조합이며, 네이티브 Wind Walk 원본으로 되돌린 것은 아니다. 각 영웅 은신기 조합과 실제 속도/기습은 게임에서 확인해야 한다.

기존 카이 쿨다운/바스테트 성역 변경, 유닛/아이템/특성/드래곤 워리어/리소스는 보존했다. 새 제목은 ver145. MPQ 교체 잔여 공간도 정리했다.

검증: 기본 능력 정의 확인, A056 원본 ID 외 능력 필드/객체 동일, 다른 객체 파일 바이트 동일, 모든 활성 파일 읽기/내용 검증, 전체 JASS 문법/타입 검사 통과. 실제 게임 실행은 불가하여 소환 제거와 효과는 인게임 확인이 필요하다. ver144는 소환 회귀가 있으므로 일반 사용 대신 ver145를 사용한다.
