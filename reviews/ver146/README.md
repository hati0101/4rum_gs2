# ver146 — 바스테트 성역 지속시간 무적 보강

ver144/145의 더미 위치·대상 수정만으로는 실제 게임에서 무적이 적용되지 않는다는 사용자 제보에 따라, ver145에 명시적인 지속시간 무적 처리를 추가했습니다.

- 최초 F8FIX(`maps/GS2vF_ver19.w3x`, 내부 vF_8FKfix)의 성역 A0JM `adur`/`ahdu`는 레벨별 2/3/4초입니다. 시전 능력 A0JL의 0.01초는 발동용 능력 지속시간으로, 무적 시간이 아닙니다.
- 시전 순간 시전자 중심 800 범위의 살아 있는 아군 생체 유닛(시전자 포함, 기계/건물 제외)에 전용 `IV46` 무적 능력을 직접 부여합니다. 선정된 대상은 범위에서 이동해도 2/3/4초 동안 보호됩니다. 뒤늦게 들어온 대상에는 이 직접 보호를 추가하지 않습니다.
- `IV46`의 원본은 실제 기본 데이터에서 무적 구현 `Avul`로 확인했습니다. 기존 부두 더미·버프·연출은 보존하여 다른 스킬의 B05M 버프 참조를 제거하지 않았습니다.
- 각 시전이 끝나면 자신이 부여한 보호 횟수를 회수합니다. 성역이 중첩되면 마지막 보호가 끝날 때 전용 능력을 제거하며, 다른 효과의 기본 `Avul`에는 손대지 않습니다. 전용 능력은 변신에서 유지하도록 설정하고, 종료 타이머·그룹·저장소는 정리합니다.
- 카이, 부츠, 사거리 표시, 드래곤 워리어 복구 및 활성 리소스는 보존했습니다. 추가/변경 능력은 기본/스킨 객체 양쪽에 반영했습니다. 맵 파일·내부 제목·시작 안내·에디터 버전은 ver146입니다.
