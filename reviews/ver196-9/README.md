### 메달 비교와 한계

nE15와 기본 시노부 n020은 같은 nfro 기반입니다. 196-8에서 둘 다 건물=1, peon 분류, 이동속도0, fly, 충돌0, 미니맵 숨김, 메달 아이콘, 빈 모델, 무적입니다. n020의 추가 능력들은 불노부 등 공유 제어용 능력이므로 돌노부에 복사하지 않았습니다. 정상 영웅의 기존 생성·연구·선택 코드도 변경하지 않았습니다. 돌노부는 변신 때 n020을 제거하고 nE15를 생성·저장하는 기존 경로를 유지합니다. **건물 분류를 다시 바꾸거나, 새 버튼을 추가하는 수정이 아닙니다.**

포커스 보강은 반복 입력을 위한 후보 조치이지, 엔진 실패 원인을 재현한 확정 수정은 아닙니다. 진단의 스크립트 클릭 횟수가 재클릭 때 늘지 않으면 입력 전달 쪽, 늘지만 즉시/지연 선택이나 현재 창 선택이 실패하면 캐시/선택 덮어쓰기 쪽을 살펴야 합니다. 실제선택이벤트에는 F8·직접 선택도 포함됩니다. 반복 재선택 루프를 추가하지 않고 기존 1회 지연 처리만 사용합니다.
